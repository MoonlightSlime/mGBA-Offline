# mGBA-Offline
A GBA, GBC, and GB emulator running from only an html file entirely offline using mGBA-wasm as a basline.

Full disclosure:
- While the actual emulator isn't vibe coded everything else like the UI is vibe coded.
- I am learning to code so I will review it by the end of the year (2026) and audit the code to make it more efficient and try to bug fix any issues that I couldn't find yet.

Files
- mGBA_Offline_vX.X.X.html

Notes
- ROMs are not included and should be legally obtained.
- Save states are stored locally in this browser profile which may be reset sometimes so backup your .sav files often.
